# Interpretable User Retention Modeling in Recommendation

**Source:** RecSys 2023 PDF (no URL provided) | **NLM source id:** 6e3b6f55-e08a-4e8e-9159-0deefceea5c9 | **Year / venue:** 2023, RecSys (best short paper) | **Affiliation:** Northeastern University (Shenyang, China) and WeChat/Tencent (Beijing, China) | **Analyzed:** 2026-09-17 (NotebookLM, 2 queries)

## 1. Summary
Standard recommenders optimize immediate feedback (clicks/CTR), which can promote clickbait and hurt retention; prior retention-aware models (RL, survival analysis, Decision Transformers) predict retention accurately but are not interpretable about *which* behaviors drive it, and there is an offline/online gap (offline predicts from a whole history; online must score individual candidate items). IURO (Interpretable User Retention-oriented Optimization) addresses this with Contrastive Multi-Instance Learning (CMIL) and Rationale Multi-Instance Learning (RMIL). **Unit of credit:** per user-item interaction — a UI retention score s_ui = FFN3(concat(user attrs, user long-term behavior, item features)) is computed for every item in a user's short-term (last-3-day) behavior sequence, then combined via instance-level attention into a user-level retention prediction. Online, candidate items are ranked by r_ui = α·ctr_ui + (1−α)·s_ui. **Outcome attributed/optimized:** next-3-day user return (offline regression/AUC), evaluated online as next-day and next-3-day retention. **Bias/confounding handling:** activity-weighted supervision — the offline retention loss is weighted by W_u = a·log(1+n_c^u) + b·log(1+n_i^u) (future 3-day click/impression counts), which dampens noise from naturally more-active users; contrastive learning (margin loss between high- and low-attention items) sharpens rare high-impact "aha items" instead of crediting all interactions equally; RMIL uses future clicks (days 1+) as external causal anchors, aligned to CMIL via Jensen-Shannon divergence, to stabilize which items get credited (raises "aha item" overlap across random seeds from ~35% to ~70%).

## 2. Evidence
Offline: ZhihuRec-1M (7,963 users, 81,214 items, 1.27M behaviors, 10 days) and an industry WeChat article-feed dataset (~1M users, 500K items, 97M behaviors, 18 days). AUC on next-3-day retention: Base MLP 0.7180 (ZhihuRec) / 0.6827 (industry); naive uniform-weighting IURO(AVG) 0.5838 / 0.6732 (worse than base — uniform credit fails); IURO(MIL) 0.8269 / 0.7209; IURO(MIL+MSS) 0.8312 / 0.7255; IURO(CMIL+MSS) 0.8437 / 0.7291; full IURO(RCMIL+MSS) 0.8445 / 0.7301 (best). Online A/B on WeChat article feed, 3M+ users: next-day retention +0.76%, next-3-day retention +0.65% vs. production control; overall CTR/dwell time held steady while "hit items" (IURO-recommended and impressed) had much higher CTR (0.129 vs 0.082) and dwell time (98.73s vs 18.86s); 34.08% of users shown novel-category "aha items" began following those categories. Survey/negative-feedback analysis: "not interested" feedback correlates with lowest next-day retention (35.38% of baseline); "low-quality content" and "advertising" also reduce retention; "repeated recommendation" and "don't like author" feedback correlate with above-average retention (heavy users still engaged).

## 3. Limitations
Naive CMIL without RMIL guidance is unstable — "aha item" overlap across random initializations only ~35%, i.e., the attribution is noisy without the rationale-alignment step. RMIL depends on having future click behavior as causal keys; sparse future logs weaken the rationale signal. Online serving combines UI score and CTR via a simple linear combination requiring manual α tuning. Short-term behavior window restricted to the latest 3 days, potentially missing longer-term retention drivers. Authors note (per NotebookLM's citation of related work) that some prior work (Cai et al., RLUR) explicitly frames retention as long-term feedback that is "hard to decompose... to each item," which IURO's paper is implicitly positioned against.

## 5. Project Relevance
- **Answers:** Q2 direct — this is the closest match found to "attribution of retention to individual in-app interactions" with a working, deployed method.
- **Attributes retention to individual interactions?** yes — computes a per-interaction (per-item) retention score s_ui for every item in a user's history via a learned scorer, aggregated with attention, and validated online.
- **Transferable components:** the per-interaction UI retention scorer and attention-aggregation architecture as a template for a per-swipe scorer; the activity-weighted supervision term W_u as a direct mechanism for down-weighting the selection-bias effect of naturally active users; the contrastive "aha item" mechanism to avoid spreading credit uniformly; RMIL's use of future behavior as a causal anchor, directly analogous to using later matches/conversations to guide which earlier swipes get credit.
- **Required changes:** extend the homogeneous item-click UI scorer to heterogeneous event types (swipe, match, message) via event-type embeddings; move from a single next-3-day binary/regression target to a recurring daily N7 window; validate whether the linear online blending (α·ctr + (1−α)·s_ui) generalizes to a ranking model that must predict incremental retention value rather than blend with CTR.
- **On last-touch:** directly relevant — the paper shows uniform/naive weighting across the interaction history (IURO-AVG) performs far worse than attention-weighted attribution (AUC 0.5838 vs 0.8445), demonstrating empirically that retention credit is highly non-uniform and that non-last-touch "aha items" earlier in the sequence are often the true drivers — a direct empirical argument against last-touch-style attribution.
- **Transfer rating:** adaptable — architecture and bias-handling mechanisms transfer well, but must be extended from homogeneous content clicks to heterogeneous swipe/match/message events and from a static 3-day target to a recurring N7 window.
