# 2017 KDD — LiJAR — Job Application Redistribution

**Title:** LiJAR: A System for Job Application Redistribution towards Efficient Career Marketplace  
**Authors:** Fedor Borisyuk, Liang Zhang, Krishnaram Kenthapadi (LinkedIn)  
**Year / venue:** 2017, KDD  
**Link:** http://theory.stanford.edu/~kngk/papers/LiJAR-SystemForJobApplicationRedistribution-KDD2017.pdf  
**Tier:** 1  
**nlm:** 11b0d239-3d33-4e8a-a366-5c87b64a3d42

## Summary
Jobs are over- or under-applied. LiJAR forecasts applications at expiration (Gamma-Poisson / NegBin) and boosts or exponentially penalizes ranking scores toward min/max application bands. Online: +12% entropy of applications, −8.7% applications to over-served jobs, +6.5% engagement on underserved jobs, +2.3% total applications.

## Project Relevance
**High analog.** Swap jobs↔people and applications↔likes: this is the redistribution layer we would put on top of a reciprocal scorer. Closest industry system to “highly desirable users cannot reply to surplus likes.”
